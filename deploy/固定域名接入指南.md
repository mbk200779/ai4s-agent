# 固定演示域名接入指南

> **状态：已完成（2026-11-11）。** 现用地址 `https://demo.mabokai.site`，Cloudflare
> 命名隧道 + 自有域名 `mabokai.site`，容器重启后不变。早前的快速隧道
> `surrey-tradition-bee-trails.trycloudflare.com` 已废弃——快速隧道每次重启都换域名，
> 不能写进提交材料，本文即为当时升级所用的两条路（留档备查）。
> 若将来换机器部署，只需要把同一个 `CLOUDFLARE_TUNNEL_TOKEN` 带过去，域名不用改。

---

## 方案 A：自有域名 + Cloudflare 命名隧道（推荐）

**成本**：域名 10~40 元/年（`.top` / `.xyz` 首年常见 9~10 元）；Cloudflare 免费套餐 0 元。
**结果**：`https://demo.你的域名.com`，永久不变、无警告页、自动 HTTPS。
**备案**：域名解析到 Cloudflare（境外），**不需要 ICP 备案**。

### 步骤

1. **买域名**
   阿里云 / 腾讯云 / Namesilo 均可，买最便宜的 `.top` 或 `.xyz` 即可，无需买任何附加服务。

2. **托管到 Cloudflare**
   注册 cloudflare.com（免费）→ Add a site → 输入域名 → 选 **Free** 计划 →
   Cloudflare 会给你两个 NS 地址，形如 `xxx.ns.cloudflare.com`。

3. **改 NS**
   回域名注册商控制台 → 域名管理 → DNS 服务器 → 改成 Cloudflare 给的那两个。
   生效通常 10 分钟~2 小时（`nslookup -type=ns 你的域名` 能看到 Cloudflare NS 即为生效）。

4. **创建隧道并拿 token**
   Cloudflare 控制台 → Zero Trust → Networks → Tunnels → Create a tunnel →
   选 **Cloudflared** → 起名 `ai4s` → 复制那串 `eyJ...` 开头的 **token**。

5. **配置公网主机名**
   同页面 Public Hostnames → Add：
   - Subdomain：`demo`（也可用 `@` 作根域名）
   - Domain：你的域名
   - Service：`HTTP` → `ai4s-gateway:80`

6. **把 token 给我**
   我执行下面这条即可上线（容器加入 ai4s 网络，直连网关）：
   ```bash
   docker run -d --name ai4s-tunnel --network 2026-10-21-16-54-36_ai4s-net \
     --restart unless-stopped cloudflare/cloudflared:latest \
     tunnel --no-autoupdate run --token <你的token>
   ```

> 为什么指向 `ai4s-gateway:80` 而不是 `web:3000`：
> 网关负责把 `/api/*` 直连后端并放宽到 300s 超时，绕过 Next.js 代理的 30 秒硬限制。

## 方案 B：ngrok 免费固定域名（零成本备选）

**成本**：0 元。**结果**：`https://xxx.ngrok-free.app`，地址固定不变。

**代价**：免费账号下，访客**第一次**打开会看到一个 ngrok 提示页
（"You are about to visit ..."，点 **Visit Site** 即可进入），之后同浏览器不再出现。
另外免费额度为 2 万请求/月、同时 1 条隧道。

### 步骤

1. 注册 ngrok.com（邮箱或 GitHub 登录）
2. 控制台 → Getting Started → 复制 **Authtoken**（`2xx...` 开头）
3. 控制台 → Universal Gateway → Domains → 领取一个免费的 `*.ngrok-free.app` 静态域名
4. 把 **token** 和 **域名** 给我，我执行：
   ```bash
   docker run -d --name ai4s-tunnel --network 2026-10-21-16-54-36_ai4s-net \
     --restart unless-stopped -e NGROK_AUTHTOKEN=<token> \
     ngrok/ngrok:latest http ai4s-gateway:80 --domain=<你的域名>
   ```

## 两条路对比

| | 方案 A：自有域名 | 方案 B：ngrok 免费 |
|---|---|---|
| 费用 | 10~40 元/年 | 0 元 |
| 地址形态 | `demo.你的域名.com` | `xxx.ngrok-free.app` |
| 警告页 | 无 | 有（首次需点一下） |
| 评审印象 | 专业 | 可接受，但略减分 |
| 可长期使用 | 是 | 是 |
| 需要你操作 | 买域名 + 改 NS + 建隧道拿 token | 注册 + 复制 token |
| 上手时间 | 30 分钟（含 NS 生效） | 5 分钟 |

**建议**：距离提交还有时间就选 A，域名是长期资产；只想尽快有个稳定地址就选 B，
后续拿到域名再切 A 也不影响（只需换 tunnel 容器，网关和 6 个服务都不用动）。

## 2026-11-04 实测踩坑记录（走通 demo.mabokai.site）

面板改版后有三处和本文旧描述不一致，按顺序都遇到了：

### 1. 报 `Unauthorized: Invalid tunnel secret`

不是网络问题，是 token 失效。token 是 JWT 形状，`base64 -d` 后可看到三段：

```
{"a":"<AccountID>","t":"<TunnelID>","s":"<Secret>"}
```

- `t` **必须**等于详情页「隧道详情 → 隧道 ID」；不等就是拿了别的隧道的 token
- 两者相等仍然报错 → 在详情页右侧点「刷新令牌」，再用新命令里的 token
- 新建隧道后第一次复制命令、但没点保存/中途刷新过页面，也会拿到过期值

`deploy/apply-tunnel.sh` 会自动做这层校验，直接粘整条 `docker run` 命令即可：

```bash
bash deploy/apply-tunnel.sh --cmd "docker run cloudflare/cloudflared:latest tunnel --no-autoupdate run --token eyJ..."
```

判断成功的唯一标准是日志出现 `Registered tunnel connection`（正常会有 4 条，connIndex 0~3）。

### 2. 选「已发布的应用程序」，不是「私有主机名」

「添加路由」弹窗四个选项里必须选**第一个「已发布的应用程序」**。选「私有主机名」只对装了 WARP 客户端的设备可见，公网打开就是 502。

### 3. Service URL 必须带 `http://`，且路径字段会被协议值污染

新版校验器要求写完整协议头，`ai4s-gateway:80` 会报「服务 URL 格式无效」：

```
http://ai4s-gateway:80     ✅
ai4s-gateway:80            ❌ 格式无效
https://ai4s-gateway:80    ❌ 容器内是明文 HTTP，握手失败
web:3000                   ❌ 绕过 Nginx，/api 全 404
```

**最容易漏的坑**：填完协议后，"HTTP" 会被顺手写进「路径 (optional)」字段。结果是云端口下发成：

```json
{"hostname":"demo.mabokai.site","path":"HTTP","service":"http://ai4s-gateway:80"}
```

此时访问 `/` 落入兜底规则 `http_status:404`，首页直接 404，但隧道状态显示「健康」，很容易误判成隧道没通。

验证方法 —— 看 cloudflared 收到的配置，`path` 字段不该存在：

```bash
docker logs ai4s-tunnel 2>&1 | grep 'Updated to new configuration' | tail -1
```

正确的应当是：

```json
{"hostname":"demo.mabokai.site","service":"http://ai4s-gateway:80"}
```

修正：编辑该路由，把「路径」里的 `HTTP` 清空保存（不允许留空时填 `/`）。

### 验收基线

```bash
for p in / /writing /qa /graph; do
  curl -sS -o /dev/null -w "$p %{http_code}\n" "https://demo.mabokai.site$p"
done
curl -sS "https://demo.mabokai.site/api/v1/health/"          # {"status":"ok","version":"v1.0.0"}
curl -sS -X POST https://demo.mabokai.site/api/v1/writing/outline \
  -H 'Content-Type: application/json' -d '{"topic":"检索增强生成综述","top_k":1}'   # 约 57s 返回 outline
```
