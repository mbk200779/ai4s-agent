## 修复评测报告 api_health 恒红问题
- 现象：网页评测报告里 api_health 一直红（Read timed out），qdrant/minio/retrieval 都绿。
- 根因：eval_service.py 的 _check_api_health() 在 FastAPI 同步 handler 内再 requests.get(localhost:8000)，uvicorn 单 worker 已占用处理线程，自请求必然 5s 超时。
- 修复：改为直接返回 ok（进程能执行到此处即 api 活着），并删掉无用 import requests。
- 生效需重建 api 镜像（api 容器无源码挂载卷，代码是 build 进镜像的）：docker compose build api 后重启。
- 改动文件：backend/app/services/eval_service.py
