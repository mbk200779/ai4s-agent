# 2026-10-21 工作日志

## AI4S 学术研究 Agent 脚手架

- 从零搭建了完整项目骨架：FastAPI 后端 + Next.js 前端 + Docker Compose 编排。
- 后端实现：PDF 上传/arXiv 导入、PyMuPDF 解析、fastembed bge-m3 + BM25 向量、Qdrant named vectors、RRF 检索、LiteLLM 问答、Semantic Scholar 引用图谱、综述与写作辅助、Celery 异步任务。
- 前端实现：上传、问答、图谱、综述、写作五个页面，使用 Next.js App Router + Tailwind。
- 文档：README.md 包含架构图、运行步骤、每个模块 3 行验收标准 + 1 句关键设计决策说明。
- 可复现性：docker-compose 固定 TEMPERATURE=0、PROMPT_VERSION=v1.0.0，embedding 模型缓存到命名卷。
- 保存为 user skill：`ai4s-academic-agent-bootstrap`。
- Phase 0 重构：docker-compose.yml 严格限定为 web/api/worker/qdrant/minio/redis 6 个服务，增加统一 bridge 网络 ai4s-net、各服务 healthcheck、MinIO 内嵌初始化脚本；新增 Makefile（up/down/logs/eval/help）与完整 .env.example。
- 论文接入与入库：实现 arxiv 单篇/sickle OAI-PMH 追新、S2/OpenAlex/Crossref 适配；Qdrant 新增 paper_meta collection 存引用关系与 influentialCitationCount；实现 body_hash + bge-m3 embedding 双重去重；新增 `backend/scripts/ingest.py` 批量入库脚本；worker 命令加入 `-B` 运行 embedded beat。
- 结构化 PDF 解析：PyMuPDF + pdfplumber 分页范围解析；新增 FigureExtractor、FormulaExtractor、ChapterParser、BibliographyExtractor；LLMClient 支持 vision 与 JSON 结构化；Celery 任务按 30 页/子任务拆分，group + chord 合并；所有 fragment（paragraph/figure/formula/table/reference/chapter）统一入 Qdrant。
- 检索层：新增 RetrievalService，显式实现 dense(bge-m3) + sparse(BM25) 双路召回与 RRF 融合；结果携带 page/paragraph/bbox/kind；SearchService 与 papers 搜索接口改用 RetrievalService；新增 `scripts/eval_retrieval.py`。
- 可溯源抗幻觉问答：新增 QAService、Provenance schema、provenance MinIO bucket；强制 LLM 每句答案后挂 [引#N]、后处理校验并替换无效引用为 [无依据]；检索无支撑或 RRF 分数低于阈值时拒答；provenance 日志写入 MinIO。
- 跨文献推理：新增 ReasoningService 与 reasoning 接口；实现多跳问答（最多 3 跳）、跨文献对比、矛盾发现；每步结论 grounding 到原文片段，矛盾显式标出并记录 chunk_id；provenance 日志扩展 reasoning_chain 字段。
- 引用图谱与综述生成：重写 graph_service，引入 `influence_score = log1p(influentialCitationCount)` 归一化与 `INFLUENCE_THRESHOLD=0.1` 过滤应付式引用；节点 `source_url` 优先 MinIO presigned 否则回退 arXiv PDF；新增 `/graph/{arxiv_id}/high-impact` 接口。review_service 强制句句引用并校验，支持 Markdown 导出到 MinIO `provenance` bucket；前端 graph/review 页面完成可视化、跳转与导出按钮。
- 写作/绘图辅助：新增 DrawingService、`backend/app/schemas/drawing.py`、`backend/app/api/v1/endpoints/drawing.py`；支持 matplotlib（受限环境执行）与 mermaid（mermaid.ink）代码生成并渲染；用请求内容 SHA256 作为 cache_key 缓存图片，保证同输入同输出；图表强制带数据来源标注；前端 writing 页面增加绘图交互，支持 PNG/SVG 导出。
- 前端 Next.js：新增 `PdfViewer` 组件（pdf.js 动态导入 + CDN worker），实现 QA 页点击引用高亮回跳 PDF 原位；graph 页支持滚轮缩放、拖拽平移、悬停提示与点跳原文；新增 `/eval` 评测报告页，可运行评测并查看历史；后端新增 `/papers/{arxiv_id}/pdf-url` 与 `/eval/*` 接口；`layout.tsx` 导航加入「评测」。
- 评测与可复现：新增 `backend/eval/golden_qa.json`（4 份 PDF 共 40 条 golden QA）、`backend/scripts/eval_runner.py`；`make eval` 一键健康检查 + QA 评测 + Markdown 报告；指标含准确率 / 引用命中率 / 拒答率 / 平均延迟；通过 `/app/.eval_cache/` 缓存实际输出并回退 golden fallback，保证两次运行 output_hash 一致、diff=0；报告保存到 `backend/eval/reports/`。
