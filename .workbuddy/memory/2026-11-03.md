## 2026-11-03 图谱数据源 S2 → OpenAlex 切换（重要）

- 背景：Semantic Scholar 无 key 被 429 限流，用户申请 key 被拒（表单屏蔽 qq/163 等国内邮箱）。决定彻底改用 OpenAlex（免费、开放、无 key、不限流）。
- 关键坑：OpenAlex 查 arXiv 论文必须用 DOI 形式 `https://doi.org/10.48550/arXiv.<id>`（`arXiv:<id>` 前缀 404）；arxiv id 不在 `ids` 字段，藏在 `locations` 的 `landing_page_url`/`pdf_url`（格式 arxiv.org/abs|pdf/XXXX.XXXXX），需正则提取。
- 引用列表用 `filter=cites:{openalex_id}` 查询（单 work 详情的 `cited_by_api_url` 为 None，不能用）。
- 改动文件：
  - `openalex_client.py`：加 `_extract_arxiv_id` 正则方法；`get_work_by_arxiv` 改用 DOI 形式；`fetch_citation_graph`/`fetch_related_arxiv_ids` 改用 filter=cites。
  - `graph_service.py`：`build_graph` 和 `get_high_impact_citations` 全部改用 OpenAlex，删除 S2 依赖（self.s2、_influence_score、_edge_weight 死代码）。
  - 文档同步：DEMO_SCRIPT.md 台词、README、ARCHITECTURE.md、技术文档.md 里的 Semantic Scholar/influentialCitationCount 改为 OpenAlex/cited_by_count。
- **性能 bug 修复**：原 build_graph 里 `d > depth` 应为 `d >= depth`，否则 depth=1 时子节点(d=1)会继续展开多查一层，导致 57 次 HTTP 请求、耗时 69s。修复后仅 2 次请求、6.6s。同时复用 fetch_citation_graph 返回的 seed（原来重复调 get_work_by_arxiv）。

- **修「渲染失败: __import__ not found」**：drawing_service 沙箱用 SAFE_BUILTINS 做 __builtins__，缺 __import__，导致 exec 里所有 import 语句必挂。修法：`_make_safe_import()` 生成受控 __import__（白名单 matplotlib/matplotlib.pyplot/numpy），注入 self.safe_builtins，_render_matplotlib 改用它。
- **连带坑**：`import matplotlib.pyplot as plt` 时 CPython 先 __import__("matplotlib.pyplot") 再 getattr(返回值,"pyplot")，受控 import 必须返回**顶层模块**（无 fromlist 时），否则报 cannot import name 'pyplot'。
- **修图片 500**：get_presigned_url 在容器内用 localhost:9000 建外部 Minio client 签名 → 容器内 localhost 不可达 → NewConnectionError（只捕了 S3Error）→ 500。修法：1) storage.get_presigned_url 改捕 Exception 降级返回 ""；2) 新增 figures 流式代理端点 GET /api/v1/drawing/figure/{key}（同 /papers/{id}/pdf 模式）+ storage.get_figure_bytes；3) drawing_service._url 返回相对路径 /api/v1/drawing/figure/{key}；4) 前端 writing/page.tsx 的 img src 和下载链接加 `${API_BASE}` 前缀。
- 端到端验证：/drawing/generate 200（BLEU 折线图代码+渲染成功），PNG 代理 200（46KB image/png）。
- 教训：容器内 presigned URL 用 localhost 签名必挂，凡浏览器要访问的 MinIO 对象一律走后端流式代理。
