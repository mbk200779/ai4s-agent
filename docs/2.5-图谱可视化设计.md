# 图谱可视化设计与实现说明

> 适用页面：`frontend/src/app/graph/page.tsx`
> 核心组件：`frontend/src/components/graph/GraphView.tsx`、`forceLayout.ts`
> 更新时间：2026-11-09

## 一、参考了哪些产品 / 文档，以及它们的关键做法

| 来源 | 关键做法 | 本项目采纳情况 |
|---|---|---|
| **Connected Papers**（connectedpapers.com） | 力导向布局（Force Directed Graph），相似论文自然聚成簇；**节点大小 = 被引次数**，颜色深浅 = 年份；种子论文用特殊描边标出；选中节点高亮它到种子论文的最短路径；另有 Prior / Derivative works 两个侧栏 | 采纳力导向布局、节点大小编码影响力、种子特殊样式、选中即高亮邻域；未采纳年份着色（后端节点暂无 `publication_year` 字段） |
| **Obsidian Graph View**（obsidian.md/help） | 悬停节点即高亮它的连线；点击打开、右键菜单；滚轮缩放 + 拖拽平移；筛选器（搜索、孤立点、仅存在文件）；Groups 按搜索词着色；Display 里有**文字淡出阈值**、节点大小、连线粗细；Forces 可调中心力 / 斥力 / 链接力 / 链接距离；Local Graph 可调深度 | 采纳悬停高亮、拖拽平移、搜索淡化、文字淡出阈值；把 Forces 做成固定参数（避免暴露过多调试项），把深度留给后端 `depth` 参数 |
| **Neo4j Bloom / Query 场景交互**（neo4j.com/docs/bloom-user-guide） | 悬停显示标签与属性；单击选中、**双击查看详情**；空白处拖拽平移；右下角缩放按钮 + **Fit to screen**；节点文字大小随节点缩放；图例里按类别设置颜色 / 大小 / 标题；右键可扩展邻居、隐藏无关节点 | 采纳「单击选中 + 双击开原文 + 适应视图 + 图例」这套映射，并保留浏览器原生 `title` 提示 |
| **Cytoscape.js 文档**（js.cytoscape.org） | `zoom` 支持**以某个渲染坐标为锚点缩放**；`viewport` 统一管理 pan/zoom；`fit` 适配视口；邻域高亮的标准写法是给非邻域元素加 `.faded { opacity: 0.2 }` | 采纳光标锚点缩放、`适应视图` 按钮、邻域淡化到 0.18 |
| **d3-force**（Observable / d3 文档） | `forceLink` 的 `distance` 控制边长、`forceManyBody` 提供斥力、`forceCenter` 保持居中，`tick` 时更新坐标 | 自研同构的弹簧 + 碰撞 + 向心三步迭代，避免引入新依赖 |
| **网络图设计实践**（rottenwifi.com 教程） | 按问题选布局，不要默认力导向；小调色板 + 图例说明；**不要只用颜色**区分；**重要信息不要只放在 hover 里**；必须提供缩放 / 平移 / 适配 / 重置，且不依赖鼠标 | 采纳图例、节点大小 + 深浅双编码、详情常驻面板（不依赖 hover）、键盘可用的按钮式缩放 |

## 二、改前的 6 个问题

1. **布局是硬编码圆环**：非种子节点等角分布在半径 220 的圆上，节点一多就挤在一起，且与引用强度无关。
2. **缩放不以光标为锚点**：滚轮只改 `scale`，内容会往画布左上角飞，想放大某个局部几乎做不到。
3. **没有邻域高亮**：只看得到 tooltip，看不出「这篇引了谁 / 被谁引」。
4. **没有筛选**：搜索、应付式引用开关都没有；`filter_perfunctory` 写死为 `true`，用户无法回看被过滤的边。
5. **标签全量硬画**：21 个 arXiv ID 直接铺在图上，互相压盖。
6. **连线方向画反**：后端边定义为 `source=种子, target=被引论文`，语义是「target 引用 source」，旧实现却画成种子指向子节点，也没有箭头。

## 三、改后的实现

### 1. 布局：同步力导向 + 冻结（`forceLayout.ts`）

- 迭代 420 次，每轮做三件事：**弹簧**（静止长度随边权增大而缩短，强引用贴着中心）、**碰撞**（`r1 + r2 + 26`，给标签留位）、**向心**（防止漂出画布）。
- 种子节点 `fixed`，永远居中。
- 算完即冻结，后续拖拽 / 悬停不会触发整图重排（Cytoscape 的「布局冻结」做法），避免节点跳动。
- 初始角度由节点 id 哈希决定，不使用随机数，保证每次刷新布局一致、截图可比。

### 2. 视觉编码

| 通道 | 含义 | 依据 |
|---|---|---|
| 节点半径 | 影响力 `influence_score`（开方压缩到 7–19px） | Connected Papers 的节点大小映射 |
| 节点填充深浅 | 同上，青色透明度 0.08 → 0.54 | 避免只靠尺寸编码 |
| 种子节点 | 实心青色 + 浅青光晕 + 更粗描边 | Connected Papers 的种子特殊样式 |
| 边粗细 | 引用含金量 `weight`（0.9 + 2.6w） | 原有语义保留 |
| 边样式 | 实线 = 有效引用，虚线 = 应付式引用 | 原有语义保留 |
| 箭头 | 统一指向被引论文（子节点 → 中心） | 修正方向错误 |

### 3. 交互

- **滚轮以光标为锚点缩放**（`MIN_K 0.35 ~ MAX_K 3.2`），公式 `t' = c - (c - t) · k'/k`。
- **背景拖拽平移**、**拖单个节点**调整位置（拖完保留，便于手工整理）。
- **悬停 / 选中高亮邻域**：非邻域元素淡化到 0.18。
- **单击选中**（底部出现详情：标题、影响力、被引、图内连边、打开原文按钮），**双击直接打开原文 PDF**（保留原「点击开原文」的能力，只是改到双击与按钮上，避免每次查看都弹新标签页）。
- **工具条**：搜索（匹配项保留、其余淡化）、应付式引用开关（无此类边时禁用并给出说明）、缩小 / 放大 / 适应视图。
- **标签防重叠**：按半径从大到小贪心占位，每个标签试 5 个纵向位置 × 3 个间距；与已有标签或任何节点圆相交就换位置，都放不下则本轮隐藏；缩放 ≥ 1.25 或节点 ≤ 9 时放宽显示条件。
- **响应式**：`ResizeObserver` 跟随容器宽度，高度按 0.6 比例夹在 420–620px。

### 4. 与原功能的一致性

- 输入 arXiv ID → `POST /api/v1/graph/build` 的调用方式、`depth=1` 不变。
- 默认视图与旧版完全一致（应付式引用仍隐藏），只是从「后端过滤」改为「后端返回全量 + 前端默认过滤」，用户可自行展开。
- 节点大小 = 影响力、边粗细 = 含金量、点击可打开原文，三条原有语义全部保留。

## 五、后续可做

- 后端 `GraphNode` 增加 `publication_year`，即可补上 Connected Papers 的「颜色 = 年份」编码。
- `depth=2` 时会真正出现子图间的交叉引用，力导向的聚类效果会比现在的星形更明显。
- 现在 `INFLUENCE_THRESHOLD = 0.1` 配 `log1p` 归一化，实际几乎不产生应付式边（实测 5 个种子全部为 0），该阈值可重新标定。
