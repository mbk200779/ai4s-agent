# 2.23 公网入口打不开的分层诊断

## 1. 现象

`https://demo.mabokai.site` 时好时坏，晚高峰几乎打不开；本地一切正常。
这是第三次出现，前两次分别定位到 Docker 引擎退出和端口映射损坏，这次是两个都不是。

## 2. 分层排查

按「客户端 → 边缘 → 隧道 → 源站 → 应用」五层逐段验证，每层都有可证伪的数字。

| 层 | 测试 | 结果 | 判断 |
| --- | --- | --- | --- |
| 应用 | `/`、`/library`、`/qa`、`/review`、`/api/v1/health/` | 全 200，7–40 ms | 正常 |
| 容器 | `docker compose ps` | 8 个容器 healthy | 正常 |
| 源站 | nginx 访问日志（Cloudflare 回源 IP） | 每个请求 `200 4961` 字节，完整 | 正常 |
| 隧道 | cloudflared 日志 | 4 条连接注册到 lax01/09/12/13，2 小时无重连 | 连接在，链路差 |
| 公网 | 首页 gzip 4.9 KB × 10 | 3/10 完整 | **异常** |
| 公网 | `/icon.svg` **231 字节** × 5 | 3/5 成功 | **异常** |
| 对照 | `cloudflare.com` 1.3 MB × 5 | **5/5 完整**，2.5–8 s | 客户端到 CF 边缘正常 |
| 网络 | `ping 104.21.7.182`（本站边缘） | 丢包 **75%**，RTT 279 ms | 异常 |
| 网络 | `ping 223.5.5.5`（对照） | 丢包 0%，RTT 42 ms | 正常 |

## 3. 关键证据

**231 字节的图标也只有 3/5 成功。**

这一条把「响应太大」「页面渲染慢」「接口超时」「首屏 JS 太多」全部排除掉了——
一个 231 字节的 SVG 不存在任何体积或计算问题，传不完只可能是连接在丢包。

**同一时刻 `cloudflare.com` 能完整下载 1.3 MB，5/5。**

这一条把「国际出口整体不通」「本机网络故障」「本机代理干扰」全部排除掉了——
1.3 MB 的数据能穿过同一条国际链路、同一个 LAX 边缘节点，说明客户端 ↔ 边缘没问题。

两条合起来，瓶颈唯一落在 **cloudflared ↔ Cloudflare 边缘** 这段回源连接上。

## 4. 试过但无效的

| 尝试 | 结果 |
| --- | --- |
| 重启隧道（重新选到 lax09/lax13/lax01/lax12） | 3/10，无改善 |
| 指定其他 CF 边缘 IP（104.16.132.229 / 162.159.140.98 等 4 个） | 各 1/4 |
| IPv6 访问 | 本机 IPv6 全局不可达，`curl -6` 直接失败 |
| 再起一个 cloudflared 副本（连接数 4→8） | 3/12，反而更差 |
| 换 QUIC 协议 | 上个月验证过被墙，现用 http2 |
| 压缩传输（gzip 4.9 KB） | 仍 3/10 |

参数层面已经没有余量：`--protocol http2`（QUIC 被墙）和 `--edge-ip-version 4`
（本机无 IPv6）本来就是这个环境的最优配置。

## 5. 结论

Cloudflare 免费隧道在国内晚高峰被调度到美西（LAX，RTT 275 ms），回源连接丢包到
60~75%。**这是链路质量问题，不是配置或代码问题**，本地调整无法解决。

关键判据记在这里，下次不用再从头查一遍：

> 如果「本地 200、nginx 回源 200 完整、cloudflare.com 大文件能下、本站 231 字节文件传不完」，
> 那就是隧道回源链路的问题，直接换通路，别再调参数。

## 6. 应对

**立即可用**：

```
http://localhost:3000        ← 本机
http://localhost:8080        ← 走 nginx，等价公网路径
http://10.110.32.40:8080     ← 同局域网的其他设备
```

**换国内通路**：`docker-compose.yml` 已加 `cpolar` 服务（profile 隔离，不影响现有部署），
接入见 `deploy/cpolar-接入指南.md`，三步：注册拿 authtoken → 填 `.env` → 
`docker compose --profile cpolar up -d cpolar`。

两条隧道可并存，国内走 cpolar、海外走 Cloudflare。
