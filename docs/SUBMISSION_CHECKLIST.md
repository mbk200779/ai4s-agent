| 要求项 | 状态 | 说明 |
|---|---|---|
| 时长 5–8 分钟 | ⬜ | 脚本已按 8 段切好，总时长约 7 分 40 秒（见 `docs/DEMO_SCRIPT.md`） |
| 内容：项目介绍 + 核心功能演示 + AI 技术亮点 | ✅ 脚本就绪 | 覆盖：定位开场 → 导入解析 → 可溯源问答（引用回跳）→ 分级置信 → 图谱 → 综述 → 库外补货 → 评测 diff=0 |
| MP4，≥1080p | ⬜ | 录屏设置见下 |
| 普通话讲解，可配字幕 | ⬜ | 建议用剪映自动生成字幕，校对专有名词（arXiv / Qdrant / bbox / RRF） |

**录制设置（照做即可）**

| 项 | 建议值 |
|---|---|
| 分辨率 | 1920×1080（浏览器全屏 F11 后录，别用 1366 缩放） |
| 帧率 | 30 fps |
| 码率 | 6–8 Mbps（文字为主，低了会糊） |
| 工具 | Windows 自带 `Xbox Game Bar`（Win+G）或 OBS |
| 音频 | 单独音轨，-16 LUFS 左右；先录屏后配音更省事 |
| 导出 | H.264 + AAC，MP4 |

**录制前 3 分钟必做**：`bash deploy/demo-check.sh --with-qa`。它会打印「可以演示 / 有 N 项注意 / N 项不通过」，并逐项给 30 秒处置建议。

**上台用 `http://localhost:8080`，不要用公网域名。** 公网链路实测 1/3~3/3 波动，录视频时卡一次就得重录。
