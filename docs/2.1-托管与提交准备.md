## 二、我整理不了的 / 必须你做的（⬜）

### 1. 初始化 Git 仓库并推送到公开平台

**原因**：当前 sandbox 没有可用 git 命令，且仓库需要你授权 GitHub / Gitee 账号。

**操作步骤**（已为你写好脚本，复制到本地终端执行即可）：

**Linux / macOS / Git Bash：**

```bash
bash scripts/git-setup.sh https://github.com/你的用户名/你的仓库名.git
```

**Windows PowerShell：**

```powershell
.\scripts\git-setup.ps1 -RepoUrl "https://github.com/你的用户名/你的仓库名.git"
```

脚本会完成：

1. `git init`
2. 配置 user.name / user.email
3. `git add .`
4. 初始提交 `init: AI4S academic agent full stack v1.0.0`
5. `git remote add origin <你的仓库地址>`
6. `git push -u origin main`

> 如果你的账号使用 HTTPS + 个人访问令牌（PAT），执行到 push 时会提示输入用户名和 PAT。

## 四、常见问题

**Q：可以直接把 .env.example 改名为 .env 提交吗？**  
A：不可以。`.env.example` 是模板，里面没有真实 key，可以提交；`.env` 已加入 `.gitignore`，不会进入仓库。

**Q：仓库太大怎么办？**  
A：确保 `.gitignore` 已排除 `node_modules/`、`.next/`、`__pycache__/`、`model_cache/`、`minio_data/`、`redis_data/`。

**Q：没有 GitHub 账号怎么办？**  
A：大赛也接受 Gitee，注册后创建公开仓库，把脚本里的 URL 换成 Gitee 地址即可。
